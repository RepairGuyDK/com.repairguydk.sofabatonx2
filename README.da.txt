SofaBaton X2 tager din universalfjernbetjening med ind i Homey via MQTT. Homey kan trykke på enhver tast på ethvert apparat i din SofaBaton - tv, forstærker, aircon, ventilator, projektor - direkte fra et Flow, og hver MQTT-knap på fjernbetjeningen kan starte et Flow den anden vej, så ét tryk fra sofaen kan dæmpe lyset, trække gardinerne for og rulle filmen.

Hub'en findes automatisk på dit netværk, og broker-indstillingerne fyldes ud for dig, så du kun mangler en MQTT-broker, som både hub'en og Homey kan nå - den gratis MQTT Broker community-app på selve Homey klarer opgaven. Tryk på Opdater enhedsliste på enheden, og dine apparater og taster dukker op som færdige dropdowns i Flow-editoren. Dette er en uofficiel community-app og er hverken tilknyttet eller godkendt af SofaBaton.
